# README 이미지

`dashboard.png`는 [기본 테마](../../src/monitor35/theme.py)의 `default_theme()`와
[앱 렌더러](../../src/monitor35/render.py)의 `render()`로 만든 480 × 320 PNG입니다.
센서를 조회하거나 USB 장치에 연결하지 않고, 설명용 `Telemetry`와 60초 `Point` 이력을 입력했습니다.
실기기 사진이나 성능 측정 결과가 아닙니다.

화면 레이아웃을 변경할 때는 같은 렌더러로 이미지를 갱신하고, [README](../../README.md)의
이미지 설명과 카드 안내도 함께 확인하세요. 앱 아이콘은 기존 `src/monitor35/assets/monitor35.png`를 직접 참조합니다.
