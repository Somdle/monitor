# Testing

AGENTS.md에 실행 명령을 모아 둔다. tests/test_session.py는 외부 Display만 fake로 대체한다.
검증: 최초 전체 전송, 변경 영역 전송, 미변경 생략, 재시도 간격, 실패 후 최신 전체 프레임,
COM 번호 변경, 복귀 시 재연결, 밝기 재적용, 주기적 전체 갱신.
test_device.py는 외부 Serial 경계에서 timeout/부분 write가 실패로 전파되는지 확인한다.
test_theme.py는 저장/읽기, 잘못된 입력 보존, 렌더링 변화를 검증한다.

UI 검증은 실제 창에서 드래그, 저장, 실행 취소, 오류 표시를 확인한다.
실기기에서는 기존 UsbMonitor 종료 후 --connect --smoke 30으로 전송한다.
실제 절전/복귀 및 USB 재삽입은 사용자와 함께 수행하며 모의 테스트와 구분해 기록한다.
화면이 실제로 보이는지와 센서가 갱신되는지는 사용자가 물리 화면에서 확인해야 한다.

test_desktop.py는 실제 Tk 창 수명을 끝까지 기다려 다음 테스트에 Tcl 인스턴스를 남기지 않는다.
네이티브 절전/복귀 메시지 전달 및 중복 복귀 알림 무시를 검증한다.
test_runtime.py는 센서 실패, 최신 snapshot 유지, worker 절전 중 전송 중지와 복귀를 검증한다.

test_sensors.py는 psutil/시간 외부 경계만 대체하여 디스크 R/W 합계, 실제 메모리, 시간 기반 속도,
누적량, 카운터 초기화, 어댑터/디스크 변경, 센서 가용성, 60초 이력 제한을 검증한다.
test_render.py는 차트 픽셀 변화, 숫자 크기 변경 및 카드 밖 침범 방지를 검증한다.
Tk 검증은 실제 앱처럼 모듈당 하나의 Tcl 인터프리터와 테스트별 Toplevel 창을 사용한다.
Windows Store Python에서 연속 Tk 인터프리터 초기화 시 ttk 파일 읽기 오류가 관측되어
동일 프로세스에 여러 Tcl 인터프리터를 만들던 테스트 수명을 수정했다.

GPU 테스트는 외부 실행파일 탐색/프로세스 실행 경계만 대체해 정상 값, N/A, 잘못된 수치,
시간 초과, 실행파일 부재, 재시도와 오래된 값 폐기를 검증한다. 렌더링 픽셀 테스트는 네 카드의
차트가 같은 하단 위치/크기를 가지며 정보 변경이 차트 아래에 그려지지 않는지 확인한다.

- test_desktop: 실제 Windows 트레이 생성, 숨긴 동안 센서 갱신, 다른 스레드의 메뉴 호출과 Tk 복원, 테마 자동 저장, 전체 종료 및 트레이 생성/저장 실패를 검증한다. 장치 연결 없이 실행한다.

- test_instance: 실제 별도 프로세스의 중복 실행 알림, 정상 종료 후 재실행, 강제 종료된 소유권 회수. test_desktop은 프로세스 간 알림으로 숨긴 기존 창을 복원하고 worker가 유지되는지 검증한다.
